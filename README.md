## Map Tiles

While many free and open-source software exists for displaying maps online (as seen above), often the satellite data itself is not free. The data is stored as **tiles**. These tiles need to be recent, cheap, and medium-high resolution for our use case. **USGS** provides free tile data from 2017-2021. **Esri** provides tiles with a free-tier + pricing plan. **Mapbox** is another popular, paid option.
